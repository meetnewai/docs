# How MeetNewAI checks listings

Source pages: <https://meetnewai.com/about> (editorial standards) · <https://meetnewai.com/models/sources> (model data sources). Editor: Kai.

## Every listing is checked on its official site

- A listing (AI tool, AI game, MCP server or agent skill) is added only after its facts are checked on the official site, repository or documentation. The listing page shows the last check date, and the open dataset carries it as `verified`.
- Descriptions are written by the MeetNewAI desk. Some listings started as leads from the [WorthToTry](https://worthtotry.com) catalogue (CC BY 4.0); every fact from a lead is re-checked on the official site and the description is our own.
- Prices and features change. When a price has not been checked yet, the listing says so ("Price not checked yet") instead of guessing.
- There are no paid placements in rankings, and no invented user counts or reviews.
- New listings carry the date they were added; listings that existed before dated additions began stay undated rather than being given an assumed date.

## Pages are organized by the job you need done

Categories group listings by use; tags need at least three entries; alternatives pages need enough same-niche alternatives; "best" pages are free or open-source subsets that differ from the full niche; use-case hubs combine entries across several steps of a workflow. Thin pages are kept out of the sitemap.

## MCP servers and agent skills

MCP records note the task the server completes, how far its permissions go and whether it is maintained. Install snippets (Claude Code, Cursor, Claude Desktop) are taken from each server's official README or docs and carry the date they were checked. See [mcp-and-skills.md](mcp-and-skills.md).

## AI models and API prices

Model pages combine third-party sources, each named on the page with its license. See [data-sources-and-attribution.md](data-sources-and-attribution.md). List prices are per 1M tokens before discounts or caching. Release dates and modalities are not shown because neither source provides them.

## Traffic figures

Traffic lines on product pages and the [traffic growth board](https://meetnewai.com/boards/traffic-growth) use [Vaneform](https://vaneform.com) monthly visit estimates, shown with their month. They are estimates, not the product's own analytics.

## Submissions

Makers can [submit a tool](https://meetnewai.com/submit) (sign-in required). Submissions go through a moderation queue before they are published.
