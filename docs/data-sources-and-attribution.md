# Data sources and attribution

| Data on MeetNewAI | Source | License / terms | In the open dataset? |
|---|---|---|---|
| Listings: name, category, tags, official URL, pricing note, check date | MeetNewAI desk, checked on each official site | Ours, CC BY 4.0 | ✅ yes |
| Leads for some listings | [WorthToTry](https://worthtotry.com) catalogue | CC BY 4.0 (facts re-checked, descriptions rewritten) | Only our re-checked fields |
| Plan prices, real price per token, benchmark snapshots | [real-api-pricing](https://github.com/Fei2411/real-api-pricing) by Fei2411 | MIT, Copyright (c) 2026 Fei2411; some usage measurements derive from Awesome Coding Plan by mahonzhan (CC BY 4.0) | ❌ not included |
| Codex Radar IQ, run cost and time, community ratings | [codexradar.com](https://codexradar.com) | Used with permission and attribution; **not for redistribution** | ❌ never included |
| Benchmark boards (e.g. Artificial Analysis, Terminal-Bench, Arena boards) | Each board's public snapshot | Linked with snapshot date | ❌ not included |
| Monthly visit estimates | [Vaneform](https://vaneform.com) | See Vaneform methodology | ❌ (see [vaneform/data](https://github.com/vaneform/data)) |

Rows from sources without an open license are left out of model pages.

## Citing MeetNewAI

Link the specific MeetNewAI page you are citing and name MeetNewAI (editor: Kai). For the listings dataset, use the attribution line in [meetnewai/data](https://github.com/meetnewai/data).
