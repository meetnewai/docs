# MeetNewAI: AI tools directory, MCP servers, agent skills and AI model comparison

[MeetNewAI](https://meetnewai.com) is a free, bilingual (English and Chinese) **AI tools directory** organized by the job you need done. It lists AI tools, browser-playable **AI games**, **MCP servers** and **agent skills**, and adds an **AI model comparison** with API prices, a **token cost calculator** and a traffic growth board. Every listing is checked on its official site and shows the check date. There are no paid placements in rankings.

## Features

- **AI tools directory**: [categories](https://meetnewai.com/categories/ai-coding) by use, [alternatives](https://meetnewai.com/alternatives/postman), [comparisons](https://meetnewai.com/compare/github-vs-postman), [free and open-source picks](https://meetnewai.com/best/free-ai-chat) and [use-case hubs](https://meetnewai.com/use-cases/academic-research).
- **MCP servers**: [MCP directory](https://meetnewai.com/mcp) with permission and maintenance notes plus install snippets for Claude Code, Cursor and Claude Desktop.
- **Agent skills**: [skills directory](https://meetnewai.com/skills).
- **AI models**: [model pages and comparisons](https://meetnewai.com/models) with benchmark snapshots and named sources; [API pricing by vendor](https://meetnewai.com/models/pricing); [API cost calculator](https://meetnewai.com/models/api-cost-calculator).
- **Traffic growth board**: [AI tools ranked by traffic growth](https://meetnewai.com/boards/traffic-growth), with Vaneform estimates.
- **AI games** that play inside the page: [/games](https://meetnewai.com/games).
- **Free AI API offers**: [/free-tokens](https://meetnewai.com/free-tokens).
- **Submit a tool**: [/submit](https://meetnewai.com/submit) (moderated).
- **Open data**: weekly snapshots of all listings in [meetnewai/data](https://github.com/meetnewai/data) (CC BY 4.0).
